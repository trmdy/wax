## Deliverables

All additive — keep every W1 metric and the existing
`harness/scoreboard.json` fields working (consumers exist; extend, don't
rename):

1. **display-string match %** — over cells where both wax and the oracle
   emit non-null `d`, exact string equality. New scoreboard row + json
   field. (Coverage = how often wax speaks; match = whether it's right.)
2. **Per-extension breakdown** — files-opened % and cell-value match %
   split by manifest `ext`, as a scoreboard table + json. The W2 gate is
   read off the xlsx row — make it unambiguous.
3. **Per-format-code display coverage** — aggregate by the oracle's `fmt`
   per cell: for the top codes by cell count, wax display coverage and
   match per code → `harness/format-coverage.json` + a short top-20 table
   in SCOREBOARD.md. If `harness/formats/corpus-formats.json` exists
   (another shard commits it), join against it; degrade gracefully when
   absent — do not depend on that branch.
4. **Mismatch triage** — `harness/triage.md` regenerated by each run: top
   disagreement buckets (wax open-failures by error code, value mismatches
   by type-pair, display mismatches by format code), each with up to 5
   example files (skip private files' paths), so adjudication is targeted.
5. **Tests** for every new comparator/aggregation path (the harness crate
   is covered by `cargo test` via the workspace-standalone manifest).
