## Scope 1 — formula evaluation engine (`caps: ["formulaEval"]`)

Own implementation, no third-party engines (HyperFormula-class licenses are
banned). Evaluate xlsx formulas for a curated function set over the whole
workbook at parse time, and re-evaluate incrementally on demand.

- **Function set (v0.4, exactly this list — unknown functions stay
  unevaluated):** arithmetic (`+ - * / ^ %`), comparisons
  (`= <> < <= > >=`), text `&` concat, `SUM`, `AVERAGE`, `COUNT`, `COUNTA`,
  `MIN`, `MAX`, `IF`, `AND`, `OR`, `NOT`, `ROUND`, `ABS`, `CONCAT`.
  References: relative/absolute A1, ranges, cross-sheet `Sheet1!A1`.
- **Dependency graph:** built once at open over formula cells; cycles
  produce a structured per-cell error value (`#CYCLE!`) — never a hang;
  eval budget per open (wall-clock cap with a loud `warnings` entry when
  exceeded — remaining cells keep file-cached values).
- **Display truth:** an evaluated cell's `d` is re-rendered from the
  computed value through wax-fmt with the cell's retained format code
  (same rule as override recompute, v0.2 A1). Evaluated cells are marked
  (`e: true` on the wire cell) so the pane can drop its stale badges for
  covered formulas; unevaluated formula cells keep today's cached-value +
  stale semantics.
- **New op `recalc { handle, overrides: [...] }`** (same override entry
  shape as export, v0.2 contract incl. A3/A4 semantics): applies the
  overrides to the in-memory model **side-effect-free for export** (layer,
  not mutation), re-evaluates dirty downstream cells, returns
  `{ changed: [{sheet, r, c, v, d, e}], evaluated, skipped }` bounded
  (cap 50k changed cells, loud truncation). The pane calls this after each
  committed edit to keep computed cells live.
- **Export interplay:** export with overrides now also re-evaluates covered
  downstream formulas so written cached values are fresh; uncovered ones
  keep the stale-drop honesty in `dropped[]`.

## Scope 2 — sheetView exposure (`caps: ["sheetView"]`)

Expose per-sheet view metadata on open/meta sheet entries (additive, flat,
always-present-under-cap like v0.3 amendment B): `frozenRows`,
`frozenCols` (integers, 0 = none) from xlsx `sheetView`/pane records; xls/
xlsb best-effort per the v0.3 pattern (declare coverage in the seal).
