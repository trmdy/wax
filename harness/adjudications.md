This ledger records disagreements where inspection shows that wax is correct
and the SheetJS oracle is wrong. A raw disagreement is never resolved in
SheetJS's favour automatically: each verdict requires file-specific evidence
and reasoning. Keep paths corpus-relative where possible and do not include
private file contents.
